# Evidence Folder

Use this folder to save remediation evidence.

For each ticket, capture:

- SAST/SCA report before remediation
- Jira or GitHub issue reference
- Pull Request link or screenshot
- Code diff summary
- Test results
- SAST/SCA report after remediation
- Deployment or release evidence
- Implementation notes
- BAU handover notes

Example file names:

- `SEC-001-sast-before.txt`
- `SEC-001-pr-summary.md`
- `SEC-001-test-results.txt`
- `SEC-001-sast-after.txt`
- `SEC-001-implementation-notes.md`
